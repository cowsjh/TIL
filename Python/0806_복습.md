## LiDAR

LiDAR은 2D 극좌표 데이터(`각도`, `거리`)로 공간을 인식 한다. 그렇기 때문에 극좌표를 직교 좌표로 바꿔주는 전처리가 필요하다.
- 원본 데이터는 *몇도 방향에서 얼마나 떨어져 있는지*를 나타낸다.
```python
#방위로 x, y 의 위치를 얻는 공식
x = np.cos(theta) * r
y = np.sin(theta) * r
```

# 전방 각도 계산
LiDAR의 전방향 부터 0 ~ 360 으로 인식 한다.
전방 $\pm$ 30 는 (0°~30°) `or` (330°~360°) 구간으로 볼 수 있다.

코드로는

30° = $\pi$/6

그러므로

+30°
- 0°~30°
- $\theta$<$\pi$/6
-30°
- 330° ~ 360°
- $\theta$ > 2$\pi$ - $\pi$/6
= (2$\pi$ - $\pi$/6) < $\theta$ < ($\pi$/6)

## SSH 키 인증
GItHub에 코드를 `push` 하거나 `pull` 할 때 private 저장소는 제한이 있을 수 있는데, 그것을 해결 하기 위해 서버나 os 에 키를 발급 받아 등록 할 수 있다.

```bash
ssh-keygen -t rsa      # 키 쌍(개인키+공개키) 생성
cat 키_경로.pub         # 공개키 내용 확인 — 이 값을 GitHub에 등록
```



## 데이터가 커지면 상대적으로 오버헤드가 비중이 줄어든다?

벡터화된 데이터는 **고정 오버헤드**를 가진다 그렇기 때문에 데이터 수가 늘어나면 원소당 연산 시간이 늘어날 지언정 오버헤드는 고정 이기 때문에 for문과 비교하자면 줄어든 것과 같이 보일 수 있다.
