## TX / RX / GND — 3선 구성

UART 연결에 필요한 단자는 세 개.

| 선 | 뜻 | 역할 |
|---|---|---|
| **TX** | Transmit | 내보내는 신호 |
| **RX** | Receive | 받는 신호 |
| **GND** | Ground | 공통 기준점 |

`X`는 통신 용어에서 transmit/receive 계열을 줄이는 관습 표기(`Tx`/`Rx`로도 씀). 보드 실크스크린에도 이 두 글자로 인쇄된다.

## 크로스 연결

내 TX를 상대의 RX에, 내 RX를 상대의 TX에 엇갈려 잇는다.

```
A.TX ───→ B.RX
A.RX ←─── B.TX
A.GND ─── B.GND
```

"내가 말하는 선"이 "상대가 듣는 선"에 닿아야 전달된다. 같은 이름끼리(TX-TX) 이으면 둘 다 내보내기만 하고 아무도 안 듣는다.

## GND를 빼먹으면 통신이 깨지는 이유

TX가 보내는 HIGH/LOW(예: 3.3V/0V)는 **그 기기 자신의 GND 기준으로 잰 값**이다. 두 기기의 GND가 안 이어져 있으면 "이쪽 0V"와 "저쪽 0V"가 어긋나, 상대가 보낸 HIGH를 내 기준으로 정확히 못 읽는다. TX/RX만 잇고 GND를 빼면 통신이 불안정하거나 아예 안 된다.

## 동기 vs 비동기 — 클럭선의 유무

수신 측이 "언제 한 비트씩 읽을지" 타이밍을 맞추는 방식의 차이.

| | 클럭선 | 타이밍을 아는 법 |
|---|---|---|
| **동기식** (SPI, I2C) | 있음 | 클럭선이 토글할 때마다 데이터선을 한 칸씩 읽음 |
| **비동기식** (UART) | 없음 | 사전에 약속한 속도(baud rate)로 각자 내부 타이머를 셈 |

**클럭선**: 한쪽이 일정 간격으로 HIGH↔LOW를 반복해 "지금 읽어라"는 박자를 알려주는 전용 선(드러머의 북에 해당).

**baud rate 약속**: UART는 그 박자 선이 없으므로, 통신 전에 양쪽 설정에 같은 속도를 박아둔다. 예를 들어 9600 bps면 비트 하나당 1/9600초 ≈ 104μs. 시작비트(idle 1 → 0으로 떨어지는 순간)를 "카운트 시작" 신호로 삼아, 각 칩 내부 타이머로 104μs씩 세며 데이터 8비트를 읽는다. 양쪽 baud rate가 하나라도 다르면 통신이 깨진다 — 선 하나를 아끼는 대신 속도를 정확히 맞춰야 하는 트레이드오프.
