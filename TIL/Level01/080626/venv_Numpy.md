- requirements.txt 에 버전을 명시해 두고 협업, 관리 한다.

## 시간 복잡도
알고리즘이 실행되는데 걸리는 시간, 주요 로직의 반복횟수를 중점으로 측정 된다.

```cpp
for ( int i = 0; i < n; ++i )
{
	#n
	for ( int j = 0; j < n; ++ j)
	{
		#n^2
}
```
n번 반복되는 반복문이 중복 되면 차수가 늘어 나게 되고
간단히 표현 하기 위해 시간 복잡도의 최고 차수를 이용해 Big-O 표기법을 쓴다.

$$
O(1)
$$
$$O(n)$$
자료의 순서와 크기에 따라 시간 복잡도는 다양하게 나오며, 그차이를 `worstcase` `averagecase` `bestcase` 로 나눌 수 있다. 

>[!note] 알고리즘의 시간 복잡도는 대부분 average case 를 말하지만 구하기 어려워 비슷한 worst case로 취급한다.



## Numpy

- Numpy는 C로 구현된 내부 루프가 여러 값을 한꺼번에 처리한다. -> 벡터화의 이점 (연산 시간 대폭 감소)
- 모든 원소가 같은 dtype의 한덩어리로 메모리에 올라간다.

## axis
바깥 리스트 에서 안쪽 리스트순으로 인덱싱을 한것이라고 생각 하면 된다. 아래의 `2차원`의 행렬을 예로 들면
```python
np.array([0,1],
		[2,3],
		[4,5])
```

axis = 0 : `[0,1]` -> `[2,3]` -> `[4,5]`
axis = 1 : `0 -> 1` , `2 -> 3`, `4 -> 5`

이런 식이다.
이렇게 차원이 높아져도 같은 방식이다. 아래는 3차원의 행렬이다
```python
np.array([[0,1],
		[2,3],
		[4,5]],
		
		[[1,5],
		[6,4],
		[5,2]])
```
axis = 0 : `[[0,1],[2,3],[4,5]] -> [[1,5],[6,4],[5,2]]`
axis = 1 : `[0,1]->[2,3]->[4,5]`, `[1,5]->[6,4]->[5,2]`
axis =2 : `0->1` `2->3` `4->5`, `1->5` `6->4` `5->2`

`sum()` 을 가정해보자
axis = 0 : `[[1,6], [8,7], [9,7]]`
axis = 1 : `[6,9],[12,11]`
axis = 2 :`[[1,5,9],[6,10,7]]`

### 불리언 마스킹
벡터화의 큰 강점을 여기서 볼 수 있다.

```python
scan = np.array([3, 4, 2, 6, 1,10])
near = scan<5
middle = near & (scan > 2)
valid = scan[near]
```

조건문으로 반복문 없이 자료에서 bool을 자료형을 만들어낼 수 있다. 그후 그것을 이용하여 True 만 걸러 낼 수 있다.
또한, 이중 조건문으로 도 사용 가능하다.
